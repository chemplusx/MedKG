How to Use Node Interaction Search

Node Interaction helps you discover connections between two entities within the knowledge graph. Follow these steps:

  1. Enter Start Node: Type the name of the starting entity (e.g., Drug, Disease, Protein).
  2. Enter End Node: Type the name of the ending entity.
  3. Specify Search Depth: Set the maximum number of connections (hops) to explore.
  4. Find Path: Click "Find Path" to visualize the shortest path between the two nodes.

The search will return the shortest path between the two nodes, if one exists, helping you understand the relationships within the graph.
