Getting started

Spin up the application server, connect to Neo4j, and import datasets with the CI/CU pipeline.

Prerequisites

  • Go 1.20+, Python 3.9+, and a running Neo4j instance (v5 or later).
  • Populate environment variables for Neo4j connection (`NEO4J_URI`, `NEO4J_USER`, `NEO4J_PASS`).
  • Run CI/CU ingestion scripts from the repository root (`python /etl_*.py`).

Running the server

cd medkg-api
go mod tidy
go run main.go

The server exposes REST endpoints at http://localhost:5000, with Swagger available at /swagger and the web client at /home.

Analysis & MedLINK

Reproduce the published MedLINK metrics and extend the analytics pipeline.

  • Use the curated CSV exports (`nodes_dd.csv`, `edges_dd.csv`) for graph ML benchmarks.
  • Train the hybrid MedLINK encoder via medlink/link_prediction.py and log metrics to metrics/.
  • Inspect loss curves, AUC/MRR plots, and reproducibility artefacts in the GitHub repository.
