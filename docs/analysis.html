Training

Run the experiment

cd medlink
python link_prediction.py \
  --epochs 1000 \
  --use_wandb 0 \
  --batch_size 1024

Override arguments inside link_prediction.py (e.g., number of layers, hidden size, dropout) to reproduce experiments.

Tips
  • Use MEDKG_DATA to point at the folder containing nodes_dd.csv and edges_dd.csv.
  • Enable Weights & Biases logging by setting use_wandb to 1.
  • Saved models (`best_model.pth`) can be loaded to score novel drug/disease pairs via helper functions in the script.
  • Evaluate additional metrics by extending the CSV logging in metrics/.
