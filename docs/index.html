Start exploring MedKG

Pick a workflow to dive straight into ingestion, exploration, or analytics.

View full pipeline

Ingest data sources

Run ETL jobs per domain folder, backed by shared helpers and environment-controlled data paths.

export MEDKG_DATA=/path/to/data
python drugbank_data/etl_drugbank.py

Launch the Go API

Serve graph search, open API documentation, and network visualisation from the `medkg-api` module.

cd medkg-api
go run main.go

Train MedLINK models

Reproduce link prediction benchmarks with tracked AUC and MRR metrics.

cd medlink
python link_prediction.py

Featured initiatives

Open-source modules that extend MedKG into production APIs, integration pipelines, and graph machine learning.

medkg-api

Graph-first Go application server

Provides Swagger/OpenAPI documentation, full-text search, path exploration, websocket streaming, and responsive UI templates for graph exploration.

  • Neo4j driver with context-aware sessions
  • Search, autocompletion, and network graph endpoints
  • Deployed HTML templates for home, docs, and search
Graph API details
MedLINK

Hybrid GNN link prediction

Trains a hybrid encoder (GCN, GAT, RGCN) to recover drug–disease relationships with reproducible metrics and W&B logging hooks.

  • 51K nodes, 46K curated edges
  • Test AUC up to 0.987 on Med-LINK
  • CSV exports for Nebula & Neo4j loaders
Review benchmarking

PrimeKG connectors

Automated transformations for Nebula Graph and Neo4j, allowing ingestion of open PrimeKG datasets.

Embedding utilities

`embed/` module generates Mol2Vec embeddings and prepares features for graph ML workloads.

Visual analytics

`visualize/` scripts and metrics dashboards track training performance, loss curves, and evaluation statistics.
